Integritetspolicy

Denna integritetspolicy beskriver hur vi behandlar personuppgifter när du besöker vår webbplats och anmäler dig till våra uppdateringar.

1. Personuppgiftsansvarig

Juridik.ai ansvarar för behandlingen av personuppgifter på denna webbplats. Vid frågor om hur dina uppgifter hanteras kan du kontakta oss på futurenomadsprojects@gmail.com.

2. Vilka uppgifter vi samlar in

När du anmäler dig via vårt formulär samlar vi in den e-postadress som du själv lämnar till oss.

3. Ändamål och rättslig grund

Vi använder din e-postadress för att skicka information och uppdateringar om Juridik.ai, inklusive information inför lanseringen. Behandlingen grundar sig på ditt samtycke, som du när som helst kan återkalla.

4. Hur länge vi sparar dina uppgifter

Vi sparar din e-postadress så länge du vill ta emot uppdateringar från oss eller tills den inte längre behövs för ändamålet. Du kan när som helst begära att bli avregistrerad genom att kontakta oss via e-post.

5. Tjänsteleverantörer och överföring av uppgifter

Vi använder externa tjänsteleverantörer för att hantera registreringar och lagra e-postadresser, bland annat Formspree. Uppgifter kan överföras till länder utanför EU/EES, där tillämpliga skyddsåtgärder används i enlighet med dataskyddslagstiftningen.

6. Dina rättigheter

Enligt dataskyddsförordningen (GDPR) har du, under tillämpliga förutsättningar, rätt att:

  • Begära tillgång till dina personuppgifter.
  • Begära rättelse eller radering av dina uppgifter.
  • Begära begränsning av behandlingen eller invända mot den.
  • Återkalla ditt samtycke när som helst.
  • I vissa fall begära att få ut dina uppgifter i ett överförbart format.
  • Lämna klagomål till Integritetsskyddsmyndigheten (IMY).

För frågor eller för att utöva dina rättigheter kan du kontakta oss på futurenomadsprojects@gmail.com.
