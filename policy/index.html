Integritetspolicy

Denna integritetspolicy beskriver hur vi behandlar personuppgifter när du besöker vår webbplats, anmäler dig till våra uppdateringar eller kontaktar oss via kontaktformuläret.

1. Personuppgiftsansvarig

Juridik.ai är ett privat projekt som drivs av [NAMN PÅ PERSONUPPGIFTSANSVARIG], som är personuppgiftsansvarig för behandlingen av personuppgifter på denna webbplats. Vid frågor om hur dina uppgifter hanteras kan du kontakta oss via vårt kontaktformulär.

2. Vilka uppgifter vi samlar in

När du anmäler dig via vårt formulär samlar vi in den e-postadress som du själv lämnar till oss.

När du kontaktar oss via kontaktformuläret samlar vi in din e-postadress, ditt meddelande och ditt namn om du väljer att ange det.

3. Ändamål och rättslig grund

Vi använder din e-postadress för att skicka information och uppdateringar om Juridik.ai, inklusive information inför lanseringen. Behandlingen grundar sig på ditt samtycke, som du när som helst kan återkalla.

Uppgifter som lämnas via kontaktformuläret används för att ta emot, hantera och besvara dina förfrågningar. Den rättsliga grunden är vårt berättigade intresse av att kunna hantera inkommande meddelanden enligt artikel 6.1 f i GDPR.

4. Hur länge vi sparar dina uppgifter

Vi sparar din e-postadress så länge du vill ta emot uppdateringar från oss eller tills den inte längre behövs för ändamålet. Du kan när som helst begära att bli avregistrerad genom att kontakta oss via vårt kontaktformulär.

Uppgifter från kontaktförfrågningar sparas så länge det behövs för att hantera ditt ärende och eventuell nödvändig uppföljning. Därefter raderas uppgifterna, om det inte finns ett särskilt skäl att behålla dem längre.

5. Tjänsteleverantörer och överföring av uppgifter

Vi använder externa tjänsteleverantörer för att hantera registreringar, kontaktförfrågningar och lagra uppgifter, bland annat Formspree. Uppgifter som skickas via formulären behandlas genom Formspree, vars tjänst använder servrar i USA.

Formspree uppger att EU:s standardavtalsklausuler används som skyddsåtgärd för internationella överföringar av personuppgifter. Mer information finns i Formsprees säkerhetsinformation.

6. Dina rättigheter

Enligt dataskyddsförordningen (GDPR) har du, under tillämpliga förutsättningar, rätt att:

  • Begära tillgång till dina personuppgifter.
  • Begära rättelse eller radering av dina uppgifter.
  • Begära begränsning av behandlingen eller invända mot den.
  • Återkalla ditt samtycke när som helst.
  • I vissa fall begära att få ut dina uppgifter i ett överförbart format.
  • Lämna klagomål till Integritetsskyddsmyndigheten (IMY).

För frågor eller för att utöva dina rättigheter kan du kontakta oss via vårt kontaktformulär.
