Integritetspolicy

Här beskriver vi hur Juridik.ai behandlar personuppgifter.

1. Ansvar och kontakt

Juridik.ai ansvarar för behandlingen av personuppgifter på webbplatsen. Du når oss via vårt kontaktformulär.

2. Uppgifter och användning

Vid anmälan samlar vi in din e-postadress för att skicka uppdateringar om Juridik.ai (samtycke).

Vid kontakt behandlar vi din e-postadress, ditt meddelande och eventuellt namn för att besvara förfrågan (berättigat intresse).

Vid besök kan tekniska uppgifter, såsom IP-adress, behandlas för webbplatsens drift och säkerhet (berättigat intresse). Uppgifterna lämnas frivilligt i formulären, men e-postadress krävs för att få uppdateringar eller svar.

3. Lagring

Anmälningsuppgifter sparas tills du avregistrerar dig eller utskicken upphör. Kontaktuppgifter sparas tills ärendet är avslutat och uppgifterna inte längre behövs. Tekniska uppgifter sparas så länge de behövs för drift och säkerhet.

4. Tjänsteleverantörer

Vi använder Formspree för att hantera formulär, externa tjänster för webbplatsens drift och Google Fonts för typsnitt. Personuppgifter kan överföras till USA med skyddsåtgärder enligt GDPR, däribland standardavtalsklausuler. Information om skyddsåtgärderna kan begäras via vårt kontaktformulär.

5. Dina rättigheter

Du kan begära tillgång till, rättelse, radering eller begränsning av dina uppgifter, invända mot behandling och i vissa fall begära dataportabilitet. Du kan när som helst återkalla ditt samtycke utan att det påverkar tidigare laglig behandling. Du har även rätt att lämna klagomål till Integritetsskyddsmyndigheten (IMY).

Kontakta oss via kontaktformuläret för att utöva dina rättigheter.
